# poki-ahh-game — Squad Rush

An original crowd-runner game: run down an endless bridge over the sea, shoot
the red crowds, pick the right gates (+, ×, ÷, ², √ …) to grow your squad, and
beat the boss at the end of each stretch.

- **`index.html`** is the browser version. It's one file, so just open it. Add `?cg50` to the URL
  for a preview of how it looks on the calculator.
  - Controls: ← → or A/D (or mouse/touch) to move, R to reset, P to pause, F for FPS.
  - Difficulties: Easy, Normal, Hard, Insane. The best score is saved separately for each one.
- **`cg50/`** is the Casio fx-CG50 add-in (C, PrizmSDK). The ready-built add-in is
  `cg50/SquadRush.g3a`; see [cg50/README.md](cg50/README.md) for install and
  build steps. It hasn't been tested much on real hardware yet.
